# CritHit! Portal Web & Admin (`/apps/web`)

Aplicação **Next.js (App Router) + React + TypeScript + Tailwind CSS + `lucide-react`** responsável pelas rotas `/` (Home Editorial SSR/ISR), `/reels` (Feed Reels 9:16), `/noticia/[slug]` (Leitor SSR/ISR) e `/admin` (Painel Editorial protegido por JWT).

> Será implementado na **Fase 4** após a conclusão das **Fases 2 e 3**.
