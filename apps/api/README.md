# CritHit! API & Worker Editorial (`/apps/api`)

Serviço backend em **Java 21 + Spring Boot 3** responsável pela API pública, API administrativa protegida por JWT, worker RSS (`Rome` + `JSoup`), deduplicação semântica no PostgreSQL 16 (`pgvector >= 0.82`), adaptação LLM em JSON estruturado e scheduler editorial.

> Será implementado na **Fase 3** após a aprovação da **Fase 2** (Arquitetura, Banco & Design System).
